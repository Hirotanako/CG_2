# Ландшафт по картам высот

## Что добавлено

`TerrainSystem` загружает полный набор 1025x1025 из корневой папки `High` через
существующий WIC-загрузчик ресурсов. `Height Output` задаёт макрорельеф, `disp`
добавляет мелкое смещение через `mask`, `diffuse` смешивается с `colormap`,
`roughness` управляет шероховатостью, а RGB `Splatmap` корректирует оттенки
типов поверхности. Высоты читаются как числовые данные без sRGB-преобразования.

Исходный проект генератора находится в `High/startup.tmd`. При сборке весь
каталог `High`, включая проект и все карты, копируется рядом с executable.

## Квадродерево и LOD

Корень покрывает весь участок 128x128. Четыре потомка делят его пополам по X и
Z; для карты 1025x1025 максимальная глубина равна 5. Сетка каждого выбранного узла имеет 32x32
квадрата. Поэтому один родитель содержит 2048 основных треугольников, а его
четыре потомка — 8192: при приближении плотность действительно увеличивается.
Удвоенная плотность промежуточных и дальних сеток уменьшает заметную
ступенчатость силуэта, сохраняя примерно тот же бюджет максимальной детализации.

Обход начинается с корня. Узел либо целиком отправляется в selection, либо
заменяется четырьмя потомками — родитель и дети одновременно не рисуются.

Для каждого узла заранее вычисляется геометрическая ошибка: максимальная
разница между исходной heightmap и билинейной поверхностью текущей сетки.
На кадре она переводится в пиксели по расстоянию вдоль направления камеры,
вертикальному FOV и высоте viewport. Узел делится, только если screen-space
error превышает 1.5 пикселя. Поэтому плоские участки остаются грубыми, а
участки с большим перепадом высот получают более подробный LOD.

Все узлы используют один индексный буфер регулярной сетки и шторок. Вызов
отрисовки меняет только `BaseVertexLocation`; дублирование индексов для каждой
ноды устранено. По каждому краю добавлена вертикальная шторка, скрывающая
T-junction между разными LOD.

## Frustum culling

Из `View * Projection` извлекаются шесть плоскостей фрустума. Для каждого узла
проверяется AABB, чьи Y-границы вычислены по фактическому минимуму и максимуму
высот (включая шторку). Только если AABB полностью снаружи хотя бы одной
плоскости, пропускается всё поддерево. Частичное пересечение не отсекается.

## Управление и проверка

- `WASD`, `Space`, `Ctrl`, правая кнопка мыши — существующая FPS-камера.
- `V` — solid/wireframe для фактической сетки ландшафта.
- `C` — включить/отключить frustum culling.
- `F` — включить вторую, обзорную камеру. Она рисует сцену со стороны, но
  выбор LOD и culling по-прежнему выполняются относительно управляемой камеры.
  Жёлто-красными линиями поверх результата показывается её frustum; дальняя
  плоскость визуализации ограничена 90 единицами для читаемости.
- В заголовке окна показаны состояния, число отправленных узлов, треугольников
  и число отсечённых поддеревьев.

Для проверки LOD включите wireframe и двигайтесь к горам/от них. Для проверки
culling остановите камеру и сравните счётчик треугольников при двух состояниях
`C`: видимая поверхность сохраняется, а число отправленных узлов уменьшается.
В режиме `F` камера продолжает управляться клавишами WASD и мышью, но экран
остаётся на обзорной камере: так непосредственно видно появление и исчезновение
узлов при пересечении боковых плоскостей frustum.
